# Ziad Invoices v3.3.28 - Login Layout Ratio Fix

UI-only update for the login screen.

- Left visual area: 66.67% (2/3)
- Right login area: 33.33% (1/3)
- The right side is approximately half the width of the left side.
- Keeps the application at real 100% browser size.
- No zoom-out and no scale-down.
- Voucher/request templates are not edited.
- Mobile/tablet uses responsive reflow instead of scaling.

Install by extracting this patch into the Ziad Invoices project root and running:

`APPLY-LOGIN-LAYOUT-v3.3.28.bat`
