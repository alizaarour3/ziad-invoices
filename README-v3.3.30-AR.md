# Ziad Invoices v3.3.30 — HTML Template First

هذا التحديث لا يستخدم صورة القالب في محرر المستندات. بدلاً من ذلك يستخدم ملفات HTML التي قدّمها المستخدم كصفحات القوالب الحقيقية داخل النظام.

القوالب:
- طلب صرف: `payment-request.html`
- مستند دفع: `payment-voucher.html`
- طلب تحويل: `request-transfer.html`
- كشف صيانة السيارات: `car-maintenance.html`

## السلوك
- واجهة النظام تبقى كما هي.
- القالب يظهر داخل محرر المستند كـ HTML حقيقي قابل للكتابة.
- الحقول تتم مزامنتها مع حقول قاعدة البيانات الموجودة، لذلك زر الحفظ الحالي يبقى يعمل.
- زر الطباعة يطبع قالب HTML نفسه، وليس صورة القالب القديمة.
- في مستند الدفع يتم الاحتفاظ بمواضع `translateY` الموجودة في القالب المرفوع حتى تظهر الكتابة فوق الخط مباشرة.
- لا يوجد تعديل بصري على ملفات HTML المرفوعة؛ يتم نسخها كما هي.

## التثبيت
شغّل `APPLY-HTML-TEMPLATES-v3.3.30.bat` من داخل مجلد المشروع.
