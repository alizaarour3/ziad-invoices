Ziad Invoices v3.3.31 - Payment Voucher Print Above Lines Fix

المشكلة:
عند طباعة مستند الدفع إلى PDF كانت بعض القيم تهبط أسفل الخط بسبب اختلاف baseline لعناصر input/textarea في وضع الطباعة.

الإصلاح:
- رفع كل حقول مستند الدفع في وضع الطباعة فقط.
- رفع أقوى للحقول الموجودة مباشرة فوق الأسطر:
  Pay to / Purpose / Written Amount / Name of Receiver / Accountant / Approval.
- رفع بسيط لباقي الحقول: رقم المستند، التاريخ، المرجع، رقم الطلب، المبلغ، العملة.
- لا يتم تحريك صورة/رسم القالب أو الخطوط.
- لا يتم تغيير تصميم القالب على الشاشة.

التثبيت:
1) ضع مجلد هذا التحديث داخل مجلد مشروع Ziad Invoices.
2) شغل APPLY-PAYMENT-VOUCHER-PRINT-FIX-v3.3.31.bat
3) أعد تشغيل النظام.
4) اطبع مستند دفع إلى PDF للاختبار.
