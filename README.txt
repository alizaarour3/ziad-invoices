Ziad Invoices v3.3.31 - Fixed Installer

This installer can be run from ANY folder.
You no longer need to put the patch folder inside the project.

1. Extract this ZIP anywhere.
2. Double-click:
   APPLY-PAYMENT-VOUCHER-PRINT-FIX-v3.3.31-FIXED.bat
3. It will automatically look for:
   C:\Users\User\Desktop\ziad-invoices-v3.3.3
4. If your project is elsewhere, paste the full project folder path when asked.
5. Restart Ziad Invoices and press Ctrl+F5 once.
6. Print a Payment Voucher to PDF.

Only payment-voucher.html is replaced. A backup of the existing file is created first.
